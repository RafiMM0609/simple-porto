# Project Guidelines & References

## Reference Documents
- **`SPEC.md`**: Master specification for architecture, concepts, sound engine, and responsive requirements.
- **`DETAILS.md`**: Primary visual refinement specifications (v1.1) for photorealistic studio integration (shadows, perspective, color grades, controls, and glassmorphic micro-interactions). **Always consult `DETAILS.md` for visual polish**.
- **`RULES.md`**: Strict constraints (Raw CSS only, no Tailwind/Bootstrap, pure vanilla JS, test suite compatibility).

## Development Commands
```bash
npm start   # Start dev server on port 3210
npm test    # Run CSS & architecture regression test suite
```
